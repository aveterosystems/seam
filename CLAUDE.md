## Agent skills

### Issue tracker

Issues live in GitHub Issues for `aveterosystems/seam`, via the `gh` CLI. Specs are local files in `specs/` (gitignored), never issues. See `docs/agents/issue-tracker.md`.

### Triage labels

The five default labels: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: root `GLOSSARY.md` plus decision records in `docs/decisions/`. See `docs/agents/domain.md`.
